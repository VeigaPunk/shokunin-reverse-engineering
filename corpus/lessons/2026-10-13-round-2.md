## Domain lessons

- **Catalog-listed ≠ provider-bound ≠ held.** Three levels: the 170-tool
  catalog lists it; `capabilities` says the *provider* declares it; only an
  end-to-end run holds it. hopper/ida ops falsely read `available:true` per-op —
  provider-level `availability.status` is the real gate. (caps-catalog)
- **Doctor is blind to aux providers.** `providerInspections` covers only
  ghidra/ida/hopper; firmware (binwalk), APK (jadx/apktool), ELF-layout
  (pwntools) readiness is invisible to `rea doctor`. Probe the verb itself.
- **Typed failure codes differ per provider layer:** `capability_unavailable`/
  `unsupported_provider` exit 0, `provider_unavailable` exits 1 retryable;
  schema errors are `invalid_request` checked *before* the provider gate.
- **`providers` ≡ `capabilities`** — identical 135KB envelope; don't run both.
- **Provider env keys discovered:** `REA_BINWALK_COMMAND`, `REA_UNBLOB_COMMAND`,
  `REA_PWNTOOLS_PYTHON`, `REA_PWNDBG_GDBINIT`, `REA_JADX_MCP_JAR`,
  `REA_JEB_MCP_URL`, `REA_ADB_PATH`, `REA_APKTOOL_COMMAND`,
  `REA_GHIDRA_STARTUP_TIMEOUT_MS` (default 330s — 40MB+ stripped binaries hit
  `provider_timeout`), `REA_IDA_MCP_CONFIG`, `HOPPER_LAUNCHER_PATH`. Version
  gates are exact: Binwalk 3.1.x, Unblob 26.6.x, JADX MCP 0.7.1, pwntools
  4.15.0/pyelftools 0.33/Unicorn 2.1.2.
- **`inspect_recorded_crash` caps at 32 MiB** decompressed — every *organic*
  core on this host (waybar 434MB, localsearch 72MB) exceeds it. Mechanism
  held; organic coverage frontier. Raw `.zst` needs caller decompress first.
- **Two snapshot formats, and they don't mix:** `--snapshot` = Analysis
  Snapshot envelope; `evidence-export/import`/`inspect-evidence-bundle` take
  only the inner `evidence_bundle` (7 keys). Feeding the envelope →
  `evidence_integrity_mismatch`. `ev_*` ids are content-addressed and
  deterministic across sessions.
- **Evidence IDs are MCP-session-scoped.** `retained-evidence` references die
  with the session (`evidence_integrity_mismatch` cross-session); CLI calls
  must inline bundles or pass file paths. (asar-deep)
- **REA rebases .so vaddrs +0x100000** — nm `jq_next` 0x17070 = REA 0x117070.
  Cross-check rule for correlating binutils output with REA addresses. (libjq)
- **`compare` needs `record_pairs` for verdicts — MCP-only.** CLI `compare`
  membership-only diff returns `status:unknown`; pairs-driven diff gives
  `changed`/`observed_change`. `function --procedure` + `compare_functions`
  gives an 8-dimension typed diff on CLI. (version-diff)
- **Static-linked stripped binaries still talk.** The jq shadow: 2,279
  procedures, zero named syms, but `JQ_BUILD_CONFIGURATION` literal +
  decNumber + ifunc relocs identified it as the stock upstream release build —
  then sha256 matched the published `jq-linux-amd64` exactly. Attribution by
  hash beats attribution by strings.
- **`--token-limit` refuses structured output** (`UNSUPPORTED_OUTPUT_COMBINATION`);
  slice with `--filter-output 'key[a:b]'`. Global `--format` goes after
  positional args. (jq-shadow)
- **uv can provision REA's Python prerequisites ad-hoc** (`uv venv --python
  3.11` + `uv pip install pwntools==4.15.0 pyelftools==0.33 unicorn==2.1.2`,
  export `REA_PWNTOOLS_PYTHON`) — demonstrated then cleaned; permanent
  provisioning remains operator-owned. (crash-probe)
