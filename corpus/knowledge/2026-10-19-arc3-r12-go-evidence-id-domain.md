## Result

`OBSERVATION` (package source) — for the measured calls, the reported Evidence ID is `ev_` plus the lowercase SHA-256 of the canonical JSON semantic projection. `dist/domain/evidence.js:159-183` defines that projection: it retains `subject.digest`, `subject.format`, and `subject.architecture`, then provider, analysis profile, predicate, operation, parameters, raw and normalized results, confidence, authority, environment, limitations, relationship coverage, locations, and evidence links; it excludes the ID itself and the subject's display fields `name` and `local_path`. `dist/domain/canonicalDigest.js:8-25,60-76` emits compact JSON, sorts object keys in RFC 8785 UTF-16 code-unit order, and hashes it with SHA-256. The independent `recompute-ids.py` uses Python `json.dumps(sort_keys=True, separators=(",", ":"), ensure_ascii=False)` instead (`recompute-ids.py:28`); that agrees with the package encoder for these payloads (all IDs match), not as a general RFC 8785 equivalence.

`OBSERVATION` (package source) — for `inspect_go_binary`, `dist/application/go/GoBinaryService.js:54-77` puts the selected path in `parameters.path`, `normalized_result.artifact.path`, and an `artifact-path` location.

`INFERENCE` — consequently those semantic fields make the ID path-sensitive in this controlled same-byte sample; the subject's display path alone does not. The observed path sensitivity is specific to this operation's projection on the measured target and call shape, not a universal rule for REA Evidence IDs.
