Refutation attempts against the tool's own claims, with verdicts:

- *"The comparator may be vacuous (everything MATCHes)."* **Refuted** — A5/A6 and
  the mutation cases inside S11/S12 produce named drift on real receipt data.
- *"sha256-only would have caught attack 3 anyway."* **Refuted** — A1's digest and
  mtime are unchanged (`SHA256-CONTRACT: 1/1 paths agree`), so a v1/sha-only
  instrument returns `MATCH`; only the v2 `ctime`/`inode` pin reports it. The v1
  sums run (c) over the same live paths is the concrete counterexample.
- *"The UTC render is really just localtime again (the v1 defect)."* **Refuted** —
  S10 asserts one identical render across `TZ=UTC/-3/+5`, and
  `label-defect-regression.out` shows the v1 string matching localtime while the
  v2 string matches `gmtime(epoch)`.
- *"A v1 receipt cannot be verified by the v2 tool."* **Refuted** — three v1
  shapes parse; `sums-v1` returns exit 0 with 5/5 sha agreement; the other two
  return the sha agreement *plus* the named label finding.
- *"capture quietly modifies the paths it records."* **Refuted for the observed
  window** — round-1 vs end-of-work digests 5/5 identical (d), and the guard case
  refuses a receipt write aimed at a custody path (exit 2, path re-hashed
  unchanged).

Residual honest limits (not defects, named): (i) a same-content rewrite that also
restores inode would need to be a ctime-preserving one, which is not achievable
from userspace — ctime cannot be set; (ii) `atime` is deliberately excluded, so
an atime-only touch is invisible — that is by design and documented, since a read
can move it; (iii) a write and a revert that both land inside the same
nanosecond would be invisible; no such operation was constructed and the
instrument's `*_NS` fields are the current resolution floor; (iv) this seat did
**not** attack a real custody path (frozen read-only rule) — that surface belongs
to EX-33's scratch-copy attack.
