### 3.3 Interim-revision finding (recorded, not suppressed)

Revision `09e270c2…` (live ~12:09-12:11Z) implemented G20 as a per-file floor
over **block-level current-ok loci**. At HEAD, SKILL.md contributes 0
current-ok blocks (its single locus-bearing block is mixed and carries block
disposition `info`), so the ordinary run read

```
$ python3 census-09e270c2.py --root . --quiet

DECLARED FAIL CLASSES: ['BLIND-INSTRUMENT']
VERDICT: FAIL  (stale=0 ambiguous=0 undeclared=0 unresolved=0)      EXIT=1
```

i.e. the clean case left the map (0 → 1), falsifying "ordinary runs at HEAD
stay PASS 0/0/0/0" for those bytes. Receipts: `logs/interim-09e270c2-clean-run.out`
plus the frozen tool copy `census-09e270c2.py`. The final revision `df9ffdf9…`
counts assertion-level dets instead (docstring: "Dets are counted, not blocks …
a block-count floor false-FAILs the ordinary run (measured; EX-14's §6 snippet
as written reproduces that false FAIL)") and restores EXIT=0 while keeping the
per-file catches (blanked/stripped SKILL → 1). Verdict on the final bytes: OK.
