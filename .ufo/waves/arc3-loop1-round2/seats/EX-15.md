   round report's wording.
2. **Floor granularity (fail-closed defect).** Folded block with mixed
   current-ok+historical asserts aggregates to `info`: r9-v1/r9-v2 floors failed
   such a tree with a real current-ok assert inside (`current-ok loci=0, total
   loci=1` / `SCORECARD.md=0`); r9-v3+ counts detections and PASSes it
   (`SCORECARD.md=1`). **Verdict: real undercount, existed in two landed
   revisions, closed by EX-16's r9-v3; independently hit by EX-14/PL-2 at HEAD
   (SKILL.md's only locus-bearing block is mixed).** Pinned by the
   `fold-mixed-block` reading case so a revert re-surfaces it.
3. **Empty-but-present CURRENT-only file (round-1 residual H1b).** Measured
   silent PASS before, declared FAIL after (G19 truncation rule).
   **Verdict: closed by the landed edit; fixture pins it.**
4. **Per-needle partial blindness (PIN alone neutered).** Not re-measured here;
   EX-16's own receipt (`receipts/after/h3-blind-pin.out`: PASS exit 0) and the
   landed header name it as residual — a token floor is not a coverage floor,
   external locus/assertion audit remains the certificate. **Verdict: residual
   stands, declared; no false claim of closure.**
