## 3. Before → after measurement (chain C3 claim)

Claim under test: "a live same-content rewrite of a custody path is detected
(inode/ctime movement) … v1 receipts remain verifiable against the tool's sha256
fields".

**Before (v1, sha256-only)** — identical-bytes rewrite, sha256 alone:

```
sha-before=aa180855543c52853e0f9a5df1b2d09b616807e50746407296bf1cfe336dc37e
sha-after =aa180855543c52853e0f9a5df1b2d09b616807e50746407296bf1cfe336dc37e
sha256-alone=silent          (logs/run.log, logs/run-real.log, cases R-B/B2/C/C2/E/D/H)
grep -c 'INODE:' round-1 v1 receipt  -> 0      (v1 cannot even express the pins)
grep -c 'CTIME'  round-1 v1 receipt  -> 0
```

**After (v2, real tool revision 112d01dc)** — every rewrite form flagged while
sha256-alone stayed silent:

```
R-B  in-place identical       -> REWRITE-DRIFT moved=mtime_ns,mtime_epoch  exit=11
R-B2 + forged mtime           -> REWRITE-DRIFT moved=ctime_ns             exit=11
R-C  rename-over + forged mtime -> REWRITE-DRIFT moved=inode              exit=11
R-C2 ln -f hardlink swap      -> REWRITE-DRIFT moved=inode                exit=11
R-E  delete+recreate + forged  -> REWRITE-DRIFT moved=inode               exit=11
R-D  same-second in-place     -> REWRITE-DRIFT moved=ctime_ns             exit=11
R-H  receipt-to-receipt pair  -> REWRITE-DRIFT moved=ctime_ns             exit=11
controls: R-A control MATCH 0 | R-G different bytes CONTENT-DRIFT 10 | R-I absent ABSENT 13
```

**Boundary (measured)**: with whole-second time fields, a same-second in-place
rewrite + forged mtime is **blind** (`--sec`: `VERDICT: MATCH exit=0`) while the
nanosecond form flags (`CTIME_UTC` drift) — the real tool's `ctime_ns` closes this
(`moved=ctime_ns`); in R-B2 `ctime_epoch` was equal and only `ctime_ns` differed.

**v1 compatibility**: `verify <round-1 v1 receipt> <fresh v2 capture>` →
`SHA256-CONTRACT: 5/5 paths agree`, `VERDICT: METADATA-DRIFT paths=5 exit=12`
with 5 declared `LABEL-DEFECT` lines (the v1 defect is surfaced, not silently
passed). So v1 sha256-field verifiability holds; a caller expecting exit 0 on a
pristine v1 receipt should expect 12.

**Claim acceptance item (landed pair)**: EX-31's `capture-pre.txt` vs
`capture-post.txt` → `MATCH paths=5/5 drift=0 exit=0`; `capture-post.txt --live` →
`MATCH 5/5 exit=0`; sidecars `OK`; EX-31 pre vs RV-12 independent capture →
`MATCH 5/5 exit=0` (`logs/ex31-pair-audit.txt`).

## 4. Attacks / refutations attempted, with verdicts

| # | attack | verdict |
|---|---|---|
| 1 | same-content rewrite, 6 forms (in-place / forged mtime / rename / hardlink / delete+recreate / same-second) | **detected** — REWRITE-DRIFT exit 11 in all six; sha256-only silent in all six (v2 claim holds) |

| 5 | benign move misclassified as tamper | **fires** — chmod-only → METADATA-DRIFT exit 12 (noise, not blindness) |
| 6 | v1 receipt silently passes despite label defect | **refuted** — exit 12 with declared LABEL-DEFECT ×5; sha256 contract 5/5 |
| 7 | tool selftest passes vacuously | **refuted** — independently run: `CLEAN cases=15 passed=15 failed=0 exit=0` (incl. the tool's own same-content-rewrite cases) |
