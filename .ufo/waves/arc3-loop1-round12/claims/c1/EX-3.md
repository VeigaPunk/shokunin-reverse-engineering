## Scope and limits

This establishes path stability only for the measured `search_bytes` semantic projection on the pinned target bytes, exact query, provider and profile. It is not “content-only”: the subject digest, provider/profile, parameters, results and other semantic fields remain in the digest. A future `search_bytes` call whose semantic result or other projected field contains a path may differ. The query is page-limited; the REA envelope itself declares `complete:false`. The Ghidra result is static analysis, not execution or proof of runtime behavior.
