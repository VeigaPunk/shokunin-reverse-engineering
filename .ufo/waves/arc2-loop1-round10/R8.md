## 3. Verbatim-landable text

**Checklist for the parent to apply at round closeout.** Land where the wave's report contract is recorded.

```markdown
### Report-contract checklist (arc2-loop1-round10, R8)

Each seat report is checked on four sections. Structural presence is near-saturated; the
discriminator is pointer resolution. Apply against the live tree, not against the tree as of
the round's start.

1. **Verdict** — a `Verdict` section, or a bolded verdict token (`PASS` / `FAIL` / `PARTIAL` /
   `ACCEPT` / `CONDITIONAL` / `UNKNOWN`) in the opening paragraph.
2. **Evidence** — an `Evidence` section carrying (a) the exact command, (b) an observed-output
   excerpt, and (c) at least one `path:line` pointer. Every pointer must resolve: the file must
   exist **and** the cited line range must be within the file. Two pointer forms are
   non-conformant and must be repaired, not waived:
   - a pointer split across a line break (`2026-10-18-arc2` + newline + `-r7-pe-wall.md:13`) —
     not copy-pasteable;
   - a `path:line` pointer into a single-line JSON/TSV artifact — the address is meaningless.
   A short alias is acceptable only if it is a suffix of the landed filename
   (`r6-midrung.md` does **not** denote `2026-10-18-arc2-r6-pe-midrung.md`).
   **Quoting rule.** A pointer that appears inside a fenced evidence excerpt is *quoted*, not
   asserted: it is the defect under review and is exempt from the resolution requirement. Only
   pointers in the report's own prose are asserted. Without this rule every reviewer or critic
   report that quotes a broken citation fails its own checklist — as this report does, since the
   ten unresolved pointers below are the defects it quotes.
3. **Verbatim-landable text** — a fenced block containing the exact text to land, where the seat
   drafts content. Omit only when the seat drafts nothing.
4. **Labels** — `observation` / `inference` / `unknown` all present and used distinctly.

**External evidence is a separate form, not a violation.** Leg scratch (`stdout.json`), custody
configs (`config.toml`), parent-directory docs (`PROTOCOL.md`, `AXES.md`) and session logs
(`wire.jsonl`) are outside the repo by construction. Cite them as an absolute path plus a
sha256, and mark the pointer `[external]`. A repo-relative `path:line` is required only for
artifacts that live in the repo.
```
