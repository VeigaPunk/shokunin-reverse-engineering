## Surviving diffs (frozen predicate blind)
- M05: `-…cases\b|…` → `+…cases|…`. Frozen predicate passes; `parse_claim("12 casesX")` → 12 (base None). Not in selftest; no population row exercises it.
- M09: `-(?<![\w./-])(\d+)/\d+ cases` → `+(\d+)/\d+ cases`. `parse_observed("ver1.45/45 cases")` → 45 (base None).
- M11: `-for text in (stdout, stderr):` → `+for text in (stderr, stdout):`. `parse_observed("cases=2","cases=9")` → 9 (base 2). Selftest has no case with both streams counting.
- M19: `-…if len(cells) >= 4 else…` → `+…>= 5…`. A 4-cell row `| tool | cases=6 | 0=ok | green, exit 0 |` yields claimed 6 (base None, row not ok). No population row has a count outside cell 4.
- M26: `-rec["green"] = rc == 0` → `+rc in (0, 1)`. An exit-1 tool printing a matching count is ok (base not ok). Neither population nor any control has a non-zero exit.
- M27: `-parse_observed(out, err)` → `+parse_observed(out, "")`. A stderr-only count tool is not ok (base ok). No population row prints its count only to stderr.
- M31: `-rec["claimed"] is not None, rec["green"],` → `+rec["claimed"] is not None,`. Same discriminator as M26 (exit-1 tool with count → ok True).

Equivalent (no observable difference): M22 (row gate makes first/last irrelevant; W-dup gives mm 7 unchanged); M29 (`rc == 0` is the definition of `green`); M30 (`agree` already requires `claimed is not None`).

## Findings (scoped; for the frozen-counter owner, not applied)
- F1 Vacuous selftest case. `claim-first-wins` takes `"15 cases at A, 16 from B"`, but `16 from B` is not an `N cases` match, so the input has one match and M06 (last-match) passes selftest. A two-match input such as `"15 cases at A, 16 cases from B"` returns 15 (base) and 16 (M06) (probe-direct.py).
- F2 `run_row` has no selftest arm. The `ok` conjunction, pin equality, duplicate gate, green gate and stderr-only counting are exercised only by the full registry run or by forgery worlds. M15/M16/M17/M18/M26/M27/M31 all pass `--selftest`. Among run_row arms, the B0/A2 population kills only M15 (agree conjunct); no population row hits pin, duplicate, green or stderr arms. The forgery worlds kill M16/M18 (W-tool-b0, pin), M17 (W-dup, duplicate gate), M25 (W-tool-b0, label arithmetic) and M23 (W-mark, marker count).
- F3 Negative boundary cases missing from selftest: `N casesX` (M05), `ver1.45/45 cases` (M09), two-stream disagreement (M11), doubled START with a single END (M23). `markers-missing` tests only zero START markers; the doubled-START branch is untested in selftest (W-mark kills M23 only through the frozen predicate's exit 2 path).
- F4 Green and exit-code gate is never exercised: no population row and no control has a non-zero exit (M26, M31 survive all frozen controls). A selftest arm with an exit-1 tool that prints a matching count should be `ok False`.
- F5 4-cell claim-column coverage: no selftest or population row places a count outside the fourth cell (M19). A negative case with `cases=N` in cell 2 would kill it.
- A2 is a weak discriminator: 27 of 32 mutants stay `met` at A2; only M01, M02, M06, M07, M32 change the A2 outcome. The B0 predicate kills M15, M24 and M28 (plus the selftest-failing parser mutants); M25 and M16/M18 are only visible in the forged-tool world.
