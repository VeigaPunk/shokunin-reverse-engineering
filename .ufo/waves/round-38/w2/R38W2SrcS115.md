## 4. Why it refuses: source evidence (new, not in the lesson)
`CPP/7zip/Archive/SquashfsHandler.cpp`, `CHandler header Parse()` (lines 229-260), identical sha256 prefix `81641fe98d2b40a4` on tags `26.04`, `26.05` and `main`; `25.01` differs in the file but has the same lines 247-249:
```
if (Major <= 3) Parse3(p);
else { if (be) return false; Parse4(p); }
```
`kSignature32_BE` sets `be = true`, and Major 4 with `be` returns false, so open fails; `Parse4` uses `LE_*` accessors only. BE is supported for v1-3 only. [INFERENCE] The refusal is by design, not corruption, since the same bytes parse under sasquatch-v4be (per wave-1/C1 evidence).
