# C1R41CounterAudit — round 50 wave 1 (pre-freeze), seat C1R41CounterAudit

Scope: audit of `tools/round-41/c1-counter.py` (3413 lines, sha256 `bbabbfec…8845cfc`, base `7c678ae6`) for every big-endian / AVM-BE assumption and every clause that would pass or fail wrongly for a little-endian `hsqs` AVM-marker carrier (R50-C1). ## Verdict

**NOT PORTABLE AS-IS. Would not score the correct R50 set green.** Defects that are verdict-blocking (C) on their own: the LE superblock is decoded big-endian (F02, F03); the `compression_coverage` binding needs a gzip carrier, which four xz carriers cannot supply (F06: the verdict can never reach exit 0); the claim literal `R41-C1` is checked in the carrier and gap-rule files (F08); the handler is `squashfs_v4_be` (F01). Wrong verdicts on correct inputs (H): `sourced` demands the single date `2026-10-26` (F07); the province token `AVM layout` is not the plan's `AVM marker` (F05). The round-41 selftest (97 cases, all BE fixtures) gives no LE coverage: its 12 green and 85 red outcomes prove only the BE path. The counter's arithmetic is sound for the BE path; the port is a rewrite of the layout and fixture layers plus the binding list, not a rename.

Two claim-level results matter for the freeze wording: (a) the AVM marker `mkfs_time == bytes_used` is **forgeable** with one environment variable (`SOURCE_DATE_EPOCH`), so `layout_ok` is a format test, not provenance (F21); (b) the 7530 carrier member carries **1,031 non-zero bytes after `bytes_used`**, so the frozen carve `length` must be `34003969`, not the member size (F22).
