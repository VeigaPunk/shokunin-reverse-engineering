rea extract-firmware — Extract selected firmware bytes and return verified files and provenance

Usage: rea extract-firmware <path> <outputDirectory> [options]

Arguments:
  path             Local firmware path; never executed
  outputDirectory  Absent output directory; parent must exist

Options:
  --offset <number>            Selected byte offset; requires length
  --length <number>            Selected byte length; requires offset
  --max-depth <number>         Extraction depth; reaching it yields partial analysis (default: 3)
  --max-output-bytes <number>  Staging file-byte budget, checked during extraction; transient overshoot is possible (default: 268435456)
  --max-output-files <number>  Staging entry budget, including directories and links (default: 10000)

Global Options:
  --filter-output <keys>              Filter output by key paths (e.g. foo,bar.baz,a[0,3])
  --format <toon|json|yaml|md|jsonl>  Output format
  --full-output                       Show full output envelope
  --help                              Show help
  --llms, --llms-full                 Print LLM-readable manifest
  --schema                            Show JSON Schema for command
  --token-count                       Print token count of output (instead of output)
  --token-limit <n>                   Limit output to n tokens
  --token-offset <n>                  Skip first n tokens of output
