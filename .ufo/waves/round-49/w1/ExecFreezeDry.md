The committed receipts will therefore say CTL-C1-4 ≠ what the plan says. I ran the plan's version by hand (X1): the counter does go red, only via `run_provenance_ok`, so the instrument is fine but the control is not the one named. Fix either side before the freeze: change the plan sentence to "round-42 heldout envelopes (H41/H43/H44/H45)", or add the round-44 copy as CTL-C1-4 (and keep heldout as CTL-C1-4b). Commands: `grep -n "HELDOUT" $W/draft/tools/round-49/c1-controls.py`; `cat tools/round-49/control-fixtures/c4/manifest.json`.

**D2 — controls driver rewrites the committed fixtures on every re-run unless `--from-fixtures` is passed.** Second run (2b) left `git status` dirty: `control-fixtures/c3/**` and `pos/**` (REA captures embed run-specific output paths/ids: c3 `evidence_id ev_f1313e32… → ev_c0e4801d…`, `after.json` 10444 → 10448 bytes) were rewritten; c1, c2, c4, c5 were byte-stable. Never run the driver bare after the freeze, and never from a cwd other than the lane/clone: `FIXTURES = 'tools/round-49/control-fixtures'` is relative to **cwd**, not `--root` (run-ctl.sh does `cd "$D"` for this reason; from the fleet root cwd it would write into the fleet repo).
