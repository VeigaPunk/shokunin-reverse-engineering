## Re-derivation method

Parsed each cited probe envelope’s raw and normalized function arrays; decoded `normalized_result.bytecode.hex`; recomputed decoded byte length and SHA-256; and checked the envelope’s artifact byte count/hash against the actual carrier file when present. Selector sets were compared to the cited pre-probe expected sets or recomputed from source/ABI signatures with the local `js-sha3` implementation. EVM opcode scans skipped PUSH immediates and stopped at the recorded Solidity metadata boundary (Vyper tables were decoded from the runtime tail).


All 21 checked probe envelopes (19 non-empty runtime cases plus two r1 creation/smoke cases) had artifact-path byte/hash fields matching the actual input bytes and decoded bytecode length/hash matching a fresh computation.
