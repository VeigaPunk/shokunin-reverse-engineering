I independently probed local carriers with REA 6.4.0 using `TMPDIR=/var/tmp/ex7-audit` and `inspect-evm-interface <path> hex --format json`. Each JSON in `.ufo/waves/arc3-loop1-round5/claims/c2/EX-7/` contains the new Evidence result and selector list. I decoded the local ABI/signature sets with the installed `js-sha3` Keccak implementation, calculated file and decoded-byte SHA-256/lengths directly, and decoded dispatcher bytecode. No target execution, chain lookup, or Core promotion was tested or implied.
