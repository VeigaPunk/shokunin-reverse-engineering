## CLAIM
All 16 sampled luna-round-6 reports contain exactly the five required level-two headings, once each and in order.

## METHOD
Sorted the top-level `.md` reports and sampled 16 evenly spaced ranks using `floor(i * population / 16)`, `i=0..15`. Checked the complete sequence of `## ` headings against `## CLAIM`, `## METHOD`, `## FINDINGS`, `## THREATS`, `## VERDICT`.

```sh
python - <<'PY'
from pathlib import Path
root = Path('.ufo/waves/luna-round-6')
files = sorted(root.glob('*.md'))
required = ['## CLAIM', '## METHOD', '## FINDINGS', '## THREATS', '## VERDICT']
sample = [(i, files[i * len(files) // 16]) for i in range(16)]
print(f'population={len(files)} sample={len(sample)}')
for i, path in sample:
    lines = path.read_text().splitlines()
    headings = [(n, line) for n, line in enumerate(lines, 1) if line.startswith('## ')]
    result = 'PASS' if [line for _, line in headings] == required else 'FAIL'
    print(f'{i * len(files) // 16 + 1} {path.name} {",".join(str(n) for n, _ in headings)} {result}')
PY
```
