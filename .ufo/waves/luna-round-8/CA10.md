## CLAIM
A zero exit, successful MCP initialization, or any JSON-RPC response alone is not a RESULT: a broken server/driver could satisfy those shallow checks without completing analysis.

## METHOD
Define L10 as RESULT only if all conditions hold: run the pinned 6.4.0 MCP server from `/tmp` within 240 seconds; its `initialize` response identifies `rea` version `6.4.0`; the chosen control verb (`analyze` or `inspect-binary-layout`) is advertised and is the exact `tools/call` request; the matching response ID contains neither JSON-RPC `error` nor `isError`; and the tool payload parses as its success schema, with a nonempty analysis/layout result, evidence ID, provider, and subject identifying `/usr/bin/jq` whose digest matches the independently recorded carrier SHA-256. Capture full request, stdout, stderr, exit, and stdout hash; require the server to exit normally after the response. Round-6 precedent captures the initialize response, call response, structured Evidence, and normal exit separately (`.ufo/waves/luna-round-6/receipts/leg-8.md:6-14,18-19`).

Any missing/truncated/malformed response, timeout, nonzero exit, mismatched server version, missing tool, error marker, empty/generic success payload, or subject mismatch is not RESULT. Because L10 expects RESULT, classify these as ERROR-UNEXPECTED (not as one of L3-L8's expected typed refusals).

## FINDINGS
The conjunction rules out the trivial false positive where an exit code or parseable envelope is mistaken for completed analysis. An actual tool-specific, jq-bound evidence payload is required.

## THREATS
This defines a gate; no L10 receipt is available in this assignment, so application of the gate and the observed 6.4.0 result remain unverified. A fabricated server could imitate the schema; these criteria detect ordinary broken-server/error misclassification, not adversarial attestation.

## VERDICT
FINDING: A shallow RESULT rule is vulnerable; classify L10 as RESULT only when every conjunctive transport, version, response, evidence, and carrier check passes.
