## C. R39-C2 (held-out triage) clauses

1. **Commit-order binding**: the held-out manifest is first added in a commit descending from the
   freeze and no later than its envelopes — the counter must read first-add commits from history,
   not trust the manifest (L4/L5).
2. **Seed reproducibility, verified**: regenerate every held-out carrier from seed = freeze hash
   at the measured rev and compare digests to the manifest; mismatch → unevaluable (L6).
3. **Table bytes pinned**: the SKILL.md craft-section triage table at the measured rev must equal
   the bytes at the freeze (the interpreter reads only the table — any other input is a defect).
4. **Label-set equality** (L21): the interpreter's output set must equal the generator's frozen
   class assignment for all N carriers, 2 per class; a catch-all or partial table scores < N and
   exits 1. The four draft kill controls (do-nothing, catch-all, gap-count-only, gap-kind-only,
   round-36 transcription) plus L16's vocabulary-only case must all be scored pre-data.
5. **avm-marker vs body-failure is NOT separable from the envelope alone** — probe evidence
   (`R38W2AvmProbe/summary.json`): the AVM-marker run shows `chunk_extraction_failed: true`,
   `gap_kind: extractor-failure`, 0 files, stderr "…suggests a SquashFS image of a different
   endianess / read_id_table: failed…"; a genuinely damaged body presents the same envelope
   shape. The discriminating test is input-side (AVM superblock rule `mkfs_time == bytes_used`,
   offsets 8/40 big-endian per the probe's `patch.rule`). Either the triage table binds this
   superblock test, or the class pair `avm-marker-be-dropped` / `body-extractor-failure` is not
   executable as drafted — resolve **before** the freeze, not after data.
6. **Classes keyed on structured fields only** (L16): `kind` (`unpublished-entry` vs
   `extractor-failure` vs `missing-extractor-dependency`), `dependencies` (`["sasquatch-v4be"]`
   vs `["sasquatch"]` for the BE/LE dependency pair), diagnostics `__typename`
   (`MaliciousSymlinkRemoved` present vs absent separates `escaping-symlink-removed` from
   `in-tree-symlink-metadata` even when both publish files), never stderr prose.
7. **`no-squashfs-chunk` distinctness** is a wave-1 recon question: if no dev carrier produces an
   envelope without any `squashfs_v4_be` chunk, the class has no generator and must be dropped
   from the frozen class set before the freeze (a class with zero held-out carriers breaks the
   "2 per class" arithmetic).
