support for v4 bigendian filesystems (#2)

There are some v4 bigendian filesystems out in the wild.
However for the v4 extraction logic the swap variable is ignored and macro
magic is used to do the swapping. Either we can change all macros to consider
the swap settings or to be more upstream compatible we just enable a compile
time flag hardcode BIG endian operation using the following:
CFLAGS=-DFIX_BE make

This would create a special sasquatch binary that would work on v4 BIG endian
images. The simple solution is to compile it twice and have a normal and a
be version.

Maybe someone with better Makefile foo can create some magic to compile it
twice.
