## 7. Variant sources (inserted verbatim before the `tree = Tree(...)` line in run_check)

Each variant is `probe-orig.py` with one of these blocks inserted and — for A/B/C —
the verdict-map CNE tuple extended with `"pointer_table_tampered"` and
`"pointer_table_unpinned"` (the same hunk PL-2's patch carries).

Variant A (fail-closed; PL-2's semantics):
```python
    try:
        _tb = open(table_path, "rb").read()
    except OSError as exc:
        findings.add("pointer_table_unreadable", os.path.basename(table_path),
                     "table bytes unreadable: %s" % exc)
        return findings
    _pin = (expected.get("pointer_table") or {}).get("sha256")
    _got = sha256_bytes(_tb)
    if _pin is None:
        findings.add("pointer_table_unpinned", os.path.basename(table_path),
                     "no table digest pinned in expected.json")
        return findings
    if _got != _pin:
        findings.add("pointer_table_tampered", os.path.basename(table_path),
                     "sha256 %s != pinned %s" % (_got, _pin))
        return findings
```

Variant B (inert when unpinned):
```python
    try:
        _tb = open(table_path, "rb").read()
    except OSError as exc:
        findings.add("pointer_table_unreadable", os.path.basename(table_path),
                     "table bytes unreadable: %s" % exc)
        return findings
    _pin = (expected.get("pointer_table") or {}).get("sha256")
    if _pin is not None and sha256_bytes(_tb) != _pin:
        findings.add("pointer_table_tampered", os.path.basename(table_path),
                     "sha256 %s != pinned %s" % (sha256_bytes(_tb), _pin))
        return findings
```

Variant C (table resolved as a Git object at --rev):
```python
    _rel = os.path.relpath(table_path, root)
    if _rel.startswith(".."):
        findings.add("pointer_table_unreadable", os.path.basename(table_path),
                     "table path outside --root; cannot resolve at %s" % rev)
        return findings
    _ttext, _terr = git_show(root, rev, _rel)
    if _terr:
        findings.add("pointer_table_unreadable", _rel,
                     "table absent at %s (%s)" % (rev, _terr))
        return findings
    _pin = (expected.get("pointer_table") or {}).get("sha256")
    if _pin is not None and sha256_bytes(_ttext.encode()) != _pin:
        findings.add("pointer_table_tampered", _rel,
                     "sha256 %s != pinned %s" % (sha256_bytes(_ttext.encode()), _pin))
        return findings
```
