   `recon` pair in `evidence-ids.txt`) — no auto-detection, no silent fallback.
   **Verdict: the encoding arg is load-bearing and positional (per PROVINCE); mismatches
   fail closed.**

   (1817 B) → 0 functions, `kind:"unknown"` (`kdx-creation.raw.json`); same on RV-2's

   the full dispatcher inside them (`ex07-crosscheck.txt`). **Verdict: refuted for this
   verb — EVMole inspects runtime blobs only on this path; creation code must not be
   used as the probe subject for selector recovery.**

   (`rv2.640.raw.json`) → identical selectors, offsets, args, mutability, bytecode sha

   same bytecode sha `b20db086…` as r3-07's carrier 1. **Verdict: the selector recovery
