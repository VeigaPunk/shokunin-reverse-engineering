## 4. Attacks / refutations (with verdicts)

1. **Wrong-hash attack** — NIST sha3-256("transfer(address,uint256)")[:4] =
   `4b40e901` ≠ `a9059cbb` (keccak). Verdict: **survived** (true Keccak in all
   three implementations; guardrail recorded in the artifact).
2. **Canonicalization attacks** — `"transfer(address, uint256)"` → `9d61d234`,
   `"transfer(address,uint)"` → `6cb927d8`, `"TRANSFER(address,uint256)"` →
   `d51e217e`. Verdict: **survived** (only canonical forms planted; recorded).
3. **Implementation triangulation** — OpenSSL vs js-sha3 vs from-spec Python:
   9/9 agreement. Verdict: **survived**.
4. **Artifact-vs-planted 4-way** — ABI-derived (solc) ≡ planted ≡ PUSH4 byte-scan ≡
   probe-recovered, zero extras. Verdict: **survived**.
5. **asm-extraction bug found** — solc `--opcodes` prints minimal digits
   (`0x6FDDE03`, `0x95EA7B3`); an 8-digit regex silently misses selectors whose
   first byte < 0x10. Verdict: **confirmed tool gotcha**, fixed (pad to 8) — noted
   in planted-selectors.txt for downstream extractors.
6. **Encoding convergence** — hex leg ≡ raw leg (set-equal), raw subject digest ==
   runtime byte sha256. Verdict: **survived**.
7. **RV-1 verifier format hazard** — their `cmp` mode takes `split()[0]` of every
   non-comment line; my two bare event-topic0 lines were counted as selectors
   (ref=11 → MISMATCH). Verdict: **confirmed**, artifact amended (topic0 lines
   comment-prefixed) before close; re-run → MATCH (hash `30b90430…` is the fixed
   file).
8. **Environment attack** — first probe died with `Unknown system error -122`
   (EDQUOT) at the worker write phase: /tmp is quota-full on this host and the
   EVMole worker writes temp files under `os.tmpdir()`. Verdict: **confirmed host
   hazard**, fixed with `TMPDIR=/var/tmp/ex03-work/tmp` (same class VZ-1 flags
   fleet-wide, `seats/VZ-1.md:126`).
9. **False-negative check** — RV-1's structural check: dispatch sites absent from
   the planted list = `[]`. Verdict: **survived**.
10. Not attempted (scope): probe on creation code; EVMole version drift (6.5.0 /
