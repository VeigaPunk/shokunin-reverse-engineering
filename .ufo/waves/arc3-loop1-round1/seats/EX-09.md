projection. Independent re-derivation from the envelope bytes reproduces
`ev_4dd5ea20…` exactly (canonical projection 9781 B), so the equality is structural, not two
equal observations.

- **B — display-field mutation** (`subject.name`, `subject.local_path` changed): id unchanged →
  the r10 exclusion statement is executable. CONFIRMED.
- **C — semantic mutation** (selector byte flipped): id changes (`ev_5e094edb…`) → B is a genuine

- **D — envelope/carrier consistency:** `sha256(bytes.fromhex(bytecode.hex))` == carrier sha256

  id changes (`ev_b2937090…`, re-derives MATCH) → the id is path-keyed; "rerun" must mean same
  path or the comparison measures the path change. CONFIRMED as a boundary, not instability.
- **G — differing id ≠ instability** (EX-05's 6.7.0 vs 6.4.0 twin on `rv2-runtime.bin`): the two
  ids differ (`ev_0636c55d…` vs `ev_76a1c1e3…`) but both re-derive MATCH under their own

  `relationship_coverage` exist only in 6.7.0). REFUTED as instability — it is a provider-version
