- **Row 189 (a receipt writer is complete JSON or absent).** A receipt writer states its own rule: every value it serializes is either JSON-encodable or is encoded first, so bytes become a length and a sha256 rather than a raw `bytes` object, and the receipt is written through a temporary file that is renamed into place only after the serializer has returned, so a receipt is complete JSON or absent and never a truncated prefix. An unknown type still raises `TypeError` rather than being coerced with `str()`. Round-93 M93-e: the frozen round-93 counter `tools/round-93/stop-boundary-repair-battery-v3.py` kept the repaired fresh cell's output bytes in `fresh_cells[*].output`, so `json.dump` raised `TypeError: Object of type bytes is not JSON serializable` on the honest case and the `--json-out` receipt was truncated inside that object. Evidence: `.ufo/waves/round-93/l1/scores/c1-pos-json-stderr-at-ca5aa6a2.txt`, `.ufo/waves/round-94/pre/c1-base-v3-pos.stderr`, `.ufo/waves/round-94/pre/c1-base-v3-F3.json`, and the successor writer `tools/round-94/stop-boundary-repair-battery-v4.py` (`write_receipt`, `default`).

- **Row 190 (a frozen counter is proven only through its public command).** A frozen counter is proven only through its public command: the honest case is run through the public command with its receipt flag, the receipt that command writes is re-read by a JSON parser and must parse as a whole, and the stdout verdict must agree with it. A helper-only selftest that exercises a writer's helpers, or a selftest belonging to a different counter, proves nothing about the public path and is not counted. Round-93 M93-e: the round-93 battery carries no `--selftest` of its own, so the helper-only selftest of the round's other counter was green while the public `--json-out` path crashed on the honest case; the successor's `--selftest` likewise exercises only the writer helpers, so the claim's evidence is the public-CLI runs. Evidence: `.ufo/waves/round-93/l1/scores/c2-selftest-at-ca5aa6a2.txt`, `.ufo/waves/round-93/l1/scores/c1-pos-json-stderr-at-ca5aa6a2.txt`, `.ufo/waves/round-94/pre/c1-base-v3-pos.stderr`, `.ufo/waves/round-94/pre/c1-v4-selftest.txt`, and the agreement counter `tools/round-94/c1-receipt-agreement.py`.
