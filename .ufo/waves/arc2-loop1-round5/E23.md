### Command A replay against the exact archived trees

The archive pairs used were `4b806e1`→`df31bfb`, `165057e`→`b21c0da`, `679af5d`→`dbba2dd`, and `158a966`→`265e1aa`; each tree was made with `git archive <rev> | tar -x -C /var/tmp/arc2-l5r5-E23-<tree>`. The calculation follows the recipe at `SCORECARD.md:92-123`, reads the extracted archive files, and was invoked exactly as `python3 - <<'PY'` from the repository root; the script body follows:

```python
from pathlib import Path
import re, json
pairs = [('r1-before','4b806e1'),('r1-after','df31bfb'),('r2-before','165057e'),('r2-after','b21c0da'),('r3-before','679af5d'),('r3-after','dbba2dd'),('r4-before','158a966'),('r4-work','265e1aa')]
for name, rev in pairs:
    root = Path('/var/tmp/arc2-l5r5-E23-' + name)
    stems = {p.stem for p in (root/'corpus/knowledge').rglob('*.md')}
    section = (root/'corpus/README.md').read_text().split('## Coverage map\n',1)[1].split('\n## ',1)[0]
    mapped = set(re.findall(r'2026-10-\d{2}-[a-z0-9-]+', section))
    craft = (root/'SKILL.md').read_text().split('## Queue-drain craft ',1)[1].split('\n## ',1)[0]
    rules = re.split(r'(?m)^- \*\*', craft)[1:]
    pat = r'corpus/knowledge/([a-z0-9-]+\.md)(?::(\d+)(?:-(\d+))?)?'
    resolved = 0
    for rule in rules:
        refs = re.findall(pat, rule); valid = bool(refs)
        for fn, first, last in refs:
            try:
                n = len((root/'corpus/knowledge'/fn).read_text().splitlines())
                lo, hi = int(first or 1), int(last or first or 1)
                valid &= 1 <= lo <= hi <= n
            except OSError:
                valid = False
        resolved += valid
    print(json.dumps({'tree':rev, 'mapped':len(stems & mapped), 'knowledge_files':len(stems),
      'missing':sorted(stems-mapped), 'dangling':sorted(mapped-stems),
      'citation_resolved_rules':resolved, 'rule_blocks':len(rules),
      'coverage_score':round(10*len(stems & mapped)/len(stems),2),
      'depth_score':round(10*resolved/len(rules),2)}, sort_keys=True))
```
