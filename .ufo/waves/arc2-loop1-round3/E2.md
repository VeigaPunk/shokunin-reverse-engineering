```bash
#!/usr/bin/env bash
# C1 pointer census — 2026-10-13-mcp-registrations.md -> ~/.kimi-code/config.toml
F="$1"; C="$2"; rc=0; n=0; d=0
emit() { local a=$1 b=$2 loc=$3 ptr=$4 got
  [ "$a" -eq 0 ] && return
  n=$((n+1)); got=$(sed -n "${a},${b}p" "$C")
  if grep -qF '[mcp_servers.rea]' <<<"$got" || grep -qF 'rea-agents@' <<<"$got" || grep -qF 'startup_timeout_sec' <<<"$got"; then
    printf 'LIVE  %s:%s -> config.toml:%s\n' "$F" "$loc" "$ptr"
  else
    printf 'DEAD  %s:%s -> config.toml:%s  (actual at %s: %s)\n' "$F" "$loc" "$ptr" "$a" \
      "$(sed -n "${a}p" "$C" | sed 's/^ *//')"; rc=1; d=$((d+1))
  fi
}
while IFS= read -r hit; do
  loc=${hit%%:*}; rest=${hit#*:}
  while read -r p; do
    [ -z "$p" ] && continue
    nums=$(grep -oE '[0-9]+' <<<"$p" | tr '\n' ' '); set -- $nums
    emit "${1:-0}" "${2:-${1:-0}}" "$loc" "$(tr -d ' ' <<<"$p" | sed 's/^config.toml//;s/^://;s/^lines//;s/^line//')"
  done < <(grep -oE "config\.toml[: ]+(lines? )?[0-9]+(-[0-9]+)?" <<<"$rest"
           grep -oE "sed -n '[0-9]+,[0-9]+p' [^ ]*config\.toml" <<<"$rest" | grep -oE "'[0-9]+,[0-9]+p'")
done < <(grep -n 'config\.toml' "$F")
echo "--- config.toml pointer instances=$n dead=$d ---"
exit $rc
```

## 7. Metric problem — append-only vs "dead loci N→0" (parent decision required)

The C1 claim as declared is "dead-pointer loci in the scoped set N→0 (cited line lacks
cited content)". **An append-only erratum cannot satisfy that as literally written**: the
erratum is appended, so `:11`/`:12`/`:18`/`:88` still exist and still lack the cited
content. The metric only reaches 0 if the original lines are *rewritten*, which the
corpus's append-only convention forbids (`corpus/QUALITY.md:5`: "A criterion is replaced
by a new row naming the row it supersedes, never rewritten"; this file already carries
`## Errata (round 2)` at `:82` in exactly that pattern).

Two measurable definitions, both measured this session:

- **Raw dead-pointer loci: 4 → 4** (unchanged; erratum is append-only). 5 instances → 5.
- **Dead-pointer loci unwarned by a later erratum: 4 → 0** (verified in §6.1; the
  fixture's errata section names all four). 5 instances → 0.

I recommend the parent adopt the second and restate C1 accordingly. Flagging rather than
choosing silently, because the claim's own wording is the parent's to amend.
