WHY THE MIRROR, AND WHAT IT DOES NOT PROVE
  The census is a fleet-repo instrument; it resolves each mined row's used-by path on disk
  relative to the registry's directory. Running it against the LIVE lane tree at the base would
  report E11 for the two new rows, because the entry file does not exist in the lane yet. The
  scratch mirror carries the base tree plus the three things that would be landed (two rows +
  the entry), which is the state the freeze will measure. The mirror proves the rows' FIELD
  SHAPE, id uniqueness, enum compliance, URL/scope uniqueness and used-by resolution; it does
  not prove the final tree state, which the L1's own post-landing validate must.
