- **Row 193 (a kill rule covers every gate its instrument asserts).** A frozen kill rule states the gate coverage it has over the instrument it grades: every gate the instrument asserts must be reachable by the rule's own counting commands, and every command the rule runs must be one the instrument's public surface actually offers. Two obligations follow. First, a gate is covered only by a command that reaches the gate's own level: a writer's durability is covered by an instrumented count of the durability calls the write path makes, and a mutant that removes that call survives every exit-code diff the rule runs unless the rule counts the call itself — a helper-only or selftest-only command never sees it, so a green rule with such a command measures a different instrument than the one it claims to grade. Second, the fail-closed behaviour of the instrument is covered only at the level where it lives: driving the counter's `main()` with a faked verdict is a main()-level negative control, and a rule that never calls `main()` cannot observe a removed fail-closed exit or a forced green verdict, no matter how many helper selftests it runs. Third, the probe's own verdict is covered only by a receipt-content consistency check on the probe's receipt — the verdict the probe publishes must agree with the world the receipt describes — so a probe whose verdict is hard-coded cannot pass a rule that only reads the probe's exit code. Round-95 M95-h is the defect this row states: the frozen round-95 kill rule killed only 5 of the 10 round-95 mutants because its checks never called the counter's `main()` and never ran the probe, so the fsync removal (M2), the forced self-verification (M3), the removed fail-closed exit (M4), the removed revision binding (M6) and the probe's hard-coded verdict (M10) all survived it; the survivors and the four checks that kill them are recorded in `.ufo/waves/round-95/w1/MutationC1.md` and `.ufo/waves/round-95/w1/MutationC1/mutants.md`, and the same rule re-measured with a committed receipt at `.ufo/waves/round-96/pre/c1-legacy-rule-at-base.json` (killed 5 of 10, survivors M2/M3/M4/M6/M10). The row's own limit is stated before the data: the check set is the declared one, so a gate the instrument asserts and no command reaches is still uncovered by this row's rule — coverage is claimed per named command, not over the instrument in general.

- **Row 194 (self-verification is mandatory on every exit).** An instrument that publishes a green verdict states that the verdict exists only through a verified receipt: the receipt is written, re-read and verified on every exit path, and a run that skips the verification has published nothing that can be graded. Two obligations follow. First, the receipt path is mandatory, not optional: --json-out is mandatory on the instrument's public command, and a run invoked without it refuses before scoring rather than scoring green and skipping the verification, so there is no exit on which a green verdict is unreceipted. Second, the verification may not be skipped and still counted: a run whose self-verification is skippable produces a green verdict that no receipt stands behind, which is the same unbound-receipt class the skip creates — the bound fields, the frozen label, the measured revision and the pinned bytes are checked by the verification, so skipping it leaves every one of them unbound at once. Round-95 M95-g is the defect this row states: the frozen round-95 counter skipped self-verification whenever it was run without `--json-out` and exited 0 on a met-True verdict with no receipt written and no field bound, while the same round's critic showed six receipt fields unbound and one forgery crashing on a bare `KeyError`; the evidence is `.ufo/waves/round-95/w1/CriticC1.md` (the no-json-out arm and the unbound-field table) and the committed before receipt `.ufo/waves/round-96/pre/c1-v5-admits-unbound-at-base.json` (accepted 5 of 6, one `KeyError` crash, nojson exit 0). The row's own limit is stated before the data: the rule binds a receipt to the world it claims and does not authenticate its provenance, so a wholly re-authored triple that describes the honest world consistently is still indistinguishable at the byte level.
