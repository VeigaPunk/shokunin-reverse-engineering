- **Observation (dispatch class C — `-O codesize`, a packed perfect-hash table, one or two levels):** the prologue loads the selector (`5f3560e01c`), then copies a **5-byte header** `[multiplier:2][table_base:2][count:1]`. When more than one header exists, the header is selected first — `PUSH1 5; PUSH1 5; PUSH1 <mask>; DUP4; AND; MUL; PUSH2 <header_base>; ADD; …` = `header_index = selector & mask`, `header_addr = header_base + 5*header_index`. The header then drives `index = ((selector * multiplier) >> 24) % count`; `CODECOPY` fetches the **7-byte entry** at `table_base + 7*index`; the entry is `[selector:4][handler_offset:2][tag:1]`; the selector is verified by `entry>>24 == selector`; the tag drives `(tag & 0xfe) < CALLDATASIZE | CALLVALUE * (tag & 1)` (tag = required calldata bytes | 1 for nonpayable); then `JUMP entry>>8 & 0xffff` to a JUMPDEST handler. Measured instances: K8 (single header) at 0x12b = `01 c3 01 30 08` (multiplier 0x01c3, table base 0x0130, count 8), entries in order f3,f1,f0,f6,f5,f7,f2,f4 at 0x130..0x161, handlers 91/116/141/166/191/216/241/266, all tags `0x25` (36 B calldata, nonpayable); Ex05Vault (single header) `00 37 00 f0 07` (multiplier 0x0037, base 0x00f0, count 7), handlers 91/116/144/169/194/205/216, tags `0x25` for the three nonpayable arg-taking functions, `0x24` for payable `delta(uint256)`, `0x05` for view/nonpayable zero-arg `epsilon`/`zeta`, `0x04` for payable zero-arg `eta`; CarrierV (K=15, **two headers**) level-1 at 0x537 selected by `selector & 1`, headers `00 0a 05 41 05` (multiplier 10, base 0x541, count 5) and `0a 1f 05 64 0a` (multiplier 2591, base 0x564, count 10), 15/15 entries at their own hash index. **The hash is perfect on all three sets** (8/8, 7/7, 15/15; `evidence/walk-*-codesize.json`, `evidence/two-level-codesize.txt`), which explains the form's name.
