## Verbatim — closeout command

Run from the repo root. Census (default): `python3 - << 'PY'` … `PY`. Close, only after the parent declares the window closed: `python3 - --close << 'PY'` … `PY`. Census exits 0 even if reports are still arriving, provided the roster matches the wire. `--close` exits 1 on a real gap or an extra seat file, and exits 0 only at N/N where N is the attempt-1 row count. Exit 2 means could-not-evaluate; do not record a delivery fraction from that run.
