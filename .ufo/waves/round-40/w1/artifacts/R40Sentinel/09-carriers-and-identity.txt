## the hazard, stated as a run I did NOT perform (design consequence only)
  A fresh REA run of carrier bytes X always yields the same restricted projection as any
  earlier genuine run of the same bytes X (measured: 3-way invariant, artifacts/R40Sentinel/
  07-projection-invariance/projection-invariance.txt). Therefore, for a carrier that is
  byte-identical to a round-39 carrier K*, a seat can take the committed K* receipt, edit only
  parameters.output_directory to this round's scratch segment, store the recomputed evidence
  id, and satisfy every content binding plus the rerun binding without running REA at all
  (measured: 08-xpin-forgery/xpin.txt stage 2 - the re-minted id verifies as `both`).
  => the freeze must prove that no round-40 carrier is byte-identical to K1..K6, and the
     vendor carriers (V1/V2) are new bytes by construction. Check to run at the freeze:
