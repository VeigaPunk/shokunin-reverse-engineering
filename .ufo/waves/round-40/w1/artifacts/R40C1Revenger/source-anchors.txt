file: AVM-BE-format.txt  sha256: c1c43f6f97d7477dcdab15203d11e43b49beb12e3a43a3b52bdd71b672a9a5d5
     1	This document summarizes all (so far known) technical details about a non-standard SquashFS format
     2	(called AVM-BE below) used by AVM since Fritz!OS Labor 6.35.
     3	
     4	 - AVM-BE format is a SquashFS4 based SquashFS format
     5	 - instead of the little-endian data layout (the only layout supported by the original/unmodified
     6	   code since SquashFS4) it uses the big-endian layout for most of the data stored in the SquashFS
     7	   image (to be more precise for all file system related data)
     8	 - the only data field stored in the little-endian format is the block length value at the beginning
     9	   of each block
    10	 - compression method is hardcoded to be XZ (aka LZMA2)
    11	 - it is unknown if any compressor specific option could be set - all original AVM images seen so far
    12	   have COMP_OPT flag unset
    13	 - super-block field 'mkfs_time' contains (instead of the filesystem creation time) the same value
    14	   as the super-block field 'bytes_used'
