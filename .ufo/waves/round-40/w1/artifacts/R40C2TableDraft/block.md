  `extract-firmware` envelope resolves to one of eleven labels from eight fields — `operation`,
  `provider.id`, the squashfs chunk handler, the gap kinds, the gap `dependencies`, whether a
  recorded sasquatch argv carries a standalone `-be` token, whether `MaliciousSymlinkRemoved` was
  reported, and the published file count — and every label carries one token from a closed
  ten-token action vocabulary scored with it
  (`corpus/knowledge/2026-10-26-r40-sqfs-triage-v2.md:11-21`,
  `corpus/knowledge/2026-10-26-r40-sqfs-triage-v2.md:32-53`,
  `corpus/knowledge/2026-10-26-r40-sqfs-triage-v2.md:102-111`). A receipt whose `operation` is not
  `extract_firmware` or whose `provider.id` is not `unblob` matches no row and reads
  `unclassified`, as does an envelope with no domain field, so a Ghidra `analyze_function` receipt
  is never a SquashFS verdict; the no-match pair is (`unclassified`, `none`) and there is no row
  and no action token for it (`corpus/knowledge/2026-10-26-r40-sqfs-triage-v2.md:23-30`). The
  `avm-marker-be-dropped` row keys on `-be` absent **and** a recorded `extractor-failure` **and**
  zero published files: a genuine AVM-layout body also runs without `-be` but publishes its files
  and is `clean`, and a genuine layout with the marker stripped receives `-be` and lands in
  `body-extractor-failure` — the timestamp is the trigger, the little-endian metadata block-length
  header is the format test
  (`corpus/knowledge/2026-10-26-r40-sqfs-triage-v2.md:69-81`; S112 lines 44-50). A carrier holding
  both link kinds is `mixed-symlinks`, a damaged body that still publishes files is
  `partial-body-failure`, and a clean extraction of a tree with no regular file is `clean-empty` —
  three outcomes version 1 could not label
  (`corpus/knowledge/2026-10-26-r40-sqfs-triage-v2.md:83-100`). Rows are tried top to bottom; the
  eleven feature vectors are pairwise disjoint, no cell is a bare `*`, each of the eight condition
  columns decides at least one measured case, and anything out of set is `unclassified`
  (`corpus/knowledge/2026-10-26-r40-sqfs-triage-v2.md:55-67`,
  `corpus/knowledge/2026-10-26-r40-sqfs-triage-v2.md:113-122`).
