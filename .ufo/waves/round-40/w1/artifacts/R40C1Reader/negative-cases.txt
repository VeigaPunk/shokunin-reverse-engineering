== sqfs-list.py --help
usage: sqfs-list.py [-h] [--layout {auto,le,be,avm}] [--files OUT.tsv]
                    [--nonregular OUT.tsv] [--inspect] [--selftest]
                    [image]

Independent SquashFS 4.0 oracle reader (LE, standard BE and AVM layout).

positional arguments:
  image                 SquashFS image

options:
  -h, --help            show this help message and exit
  --layout {auto,le,be,avm}
                        field layout; auto decides big-endian metadata header
                        endianness (default: auto)
  --files OUT.tsv       regular-file TSV (relpath, sha256, size)
  --nonregular OUT.tsv  non-regular TSV (relpath, kind, detail)
  --inspect             print a JSON superblock/layout/coverage summary
  --selftest            build and read self-contained images; no external tool
