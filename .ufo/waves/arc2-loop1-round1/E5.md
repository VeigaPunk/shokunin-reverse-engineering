## Method — the audit harness

`/tmp/arc2-l1r1-E5/audit.py` (scratch, this seat's namespace; read-only
against the repo). Two checks per text:

1. **Pointer resolution.** Every `path:NN` / `path:NN-NN` token is resolved
   (path via exact/corpus-knowledge/corpus-lessons lookup; span checked
   `1 ≤ a ≤ b ≤ lines(path)`), and every bare backticked `` `:NN` `` token is
   bound to the document's in-file target. Output line per citation:
   `OK`/`FAIL` + the first/last line of the span.
2. **Quoted bytes.** Each quoted phrase is checked against the cited span
   byte-contiguous; if not, against the whole file after whitespace
   collapsing (a quoted phrase spanning a line wrap in a hard-wrapped file is
   still a correct quote, flagged as `whitespace-normalized`).

Negative controls run this session:
`python3 audit.py block /tmp/arc2-l1r1-E5/negative-control.txt` → the
out-of-range pointer `corpus/knowledge/2026-10-13-r3-jq-provenance.md:200`
(line count 137) reported `FAIL ... file has 137 lines`; and an inline check
of a fabricated quote (`:60` claiming "safe and trustworthy install") →
`FAIL`, while the true quote at `:60` → `OK`.
