## 1. Decision and justification

**Decision: include.** Three independent grounds, each observed this session:

1. **The seat's own test — PROVINCE.md drift-prone values — names `.bashrc` env-key
   material explicitly.** `PROVINCE.md:15-26` is the "Drift-prone values" section;
   it pins `.bashrc:23-24` (GHIDRA_INSTALL_DIR / JAVA_HOME), `.bashrc:61`
   (REA_APKTOOL_COMMAND), and via `PROVINCE.md:47` `.bashrc:24` + `.profile:4`
   (JAVA_HOME), and via `PROVINCE.md:124-125` the `.bashrc:63` wakaru fix. All five
   pointer tokens resolve byte-exactly at those line numbers today (checked below).
   The custody pair exists to back zero-drift claims about exactly this class of
   value; excluding the file that carries them leaves the claim's own subject
   half-uncovered.
2. **A `.bashrc` drift is silently invisible to the current 3-path pair.** The 7
   `REA_*` provider keys (`~/.bashrc:58-64`) and `GHIDRA_INSTALL_DIR`/`JAVA_HOME`
   (`:23-24`) are the host-side wiring the client-config pins depend on. If
   `.bashrc:63` changed (it did once — r4u-05's misbinding, fix applied at
   `.bashrc:63`, `PROVINCE.md:124`), provider probes would change behavior while all
   three config hashes stay byte-identical: the pair would report zero drift while
   the environment actually drifted. That is the falsification case for the claim.
3. **Precedent already swept it.** luna-round-6's custody sweep was 4 paths
   including `~/.bashrc` (`.ufo/waves/luna-round-6/SE2.md:9-12`, `BC3.md:10`), and
   rounds 7/8/9 re-recorded the same `.bashrc` hash (8 in-repo record files total —
   §3.4). Round-6's own two stated threats transfer unchanged: hashes cannot exclude
   mutate-and-revert before the first capture, and mtime ordering is unsound alone
   (`BC3.md:14`). `R7.md:72` already lists the 3-file-only scope as a limitation.

**`.profile` — same test, stronger gap.** It is the *sole* carrier of 6 `REA_*` keys
for POSIX login shells (`sh -l` sees 8 keys; `.bashrc` alone would not supply them —
§3.3), it is cited by the same drift-prone section (`PROVINCE.md:47`), and it has
**zero** in-repo hash records (`grep -rn '6c6be761'` → 0 hits). `.bash_profile`
(`a21bfd7d…`) is **excluded**: 8 lines that source `.bashrc` and prepend
`~/.local/bin` to PATH; it carries no `REA_`/`GHIDRA`/`JAVA` export of its own.
