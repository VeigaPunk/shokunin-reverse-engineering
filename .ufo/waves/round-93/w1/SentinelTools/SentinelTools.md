## Passes (exercised)

- **Scratch (fleet rule 4), counters:** `TMPDIR=/nonexistent` under `strace -f` for v3 positive, F1, F2, F3, checker `--selftest` and checker `--manifest`: zero `"/tmp/` refs; the only write-ish paths outside `--work` are `/dev/null` (subprocess). `receipts/strace/strace-v3-*.txt.gz`, `strace-c2-*.txt.gz`. The `/tmp` substring match on `…/work/v3-pos/tmp` was a false positive; literal `"/tmp/` count is the test.
- **`--work` through a symlinked ancestor:** selftest writes land only in the symlink target tree (`realwork/selftest`). No escape. `--root ..` → checker exit **2**.
- **Shell injection:** no `shell=True`, `os.system`, or `popen` in the counters or controls (grep). `--expect '$(touch …)'` and `--rev '$(touch …)'` on v3 leave no file (early exit, not reached); checker `--rev 'HEAD;touch …'`, `'$(touch …)'`, and `'HEAD\n--output=…'` → exit **2**, inert.
- **Manifest regex / control chars:** `row_snippet` `(`, `[a-z`, `.*`, and a newline-suffixed snippet are matched literally (`row not found`, exit 1, no crash). Control chars in keywords (`\x00`, `\x07`) are literal. `num` is never taken from the manifest; it is `int()` of the criterion's `QUALITY (\d+)`.
- **C1 calibration side:** F1 and F2 both met False under v3 with fresh near cells unrepaired (`fresh-roundtrip 0 of 2`). F1 `intact 5 of 6`, F2 `intact 6 of 6` but near cells fail. Receipts: `receipts/v3/v3-F1.json`, `v3-F2.json`.
- **F2 module isolation:** the `upx_green` patch binds only the `cand` module's global (`cand` is not registered in `sys.modules`; `rep91()` modules are separate objects and do not call `upx_green`). Each F2 cell is a separate `python3 -I` child, so no leak into the counter process.
- **C2 before-manifest at base:** exit **1** with the frozen atom `row 'intact input refused by mistake': QUALITY 169 lacks ['never refuse an intact input', "packer's verdict"]` (matches the pre receipt). Selftest: `SELFTEST cases=10 failures=0`, exit 0 (also under `--work` through a symlink).
