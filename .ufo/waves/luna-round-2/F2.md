## CLAIM
A reproducible pre/post token census can catch inventory drift by immutable Git revision, scoped to the presumed current-summary blocks: `PROVINCE.md:8-10,13-18` and `SKILL.md:11-22`. The planned move is `SCORECARD.md:151-153`; live totals and the no-holdings constraint are `SCORECARD.md:56-62`.

## METHOD
Read only `git show` objects. Baseline HEAD was `a4bd355e216bff474c0cb2fc824d712c28a44cac`. First design: aggregate token counts over both files. Attack: swap equal version tokens between a surface statement and a differently labeled statement; the aggregate histogram is unchanged although attribution is wrong. Iteration: report counts independently for each anchored block. Tested final command with PRE=POST=HEAD; it returned the same pre/post buckets.

```bash
python3 - "$PRE" "$POST" <<'PY'
import collections, json, re, subprocess, sys
pre, post = sys.argv[1:]
ranges = [('PROVINCE.md','surface-summary','Surface summary:',None),
 ('PROVINCE.md','drift-prone-values','Drift-prone values:',None),
 ('SKILL.md','domain','## Domain','## Working contract')]
pat = re.compile(r'rea-agents@\d+\.\d+\.\d+|\b(?:REA\s+)?skill(?:\s+version)?\s+\(?v\d+\)?', re.I)
def block(rev, path, start, end):
 s = subprocess.check_output(['git','show',f'{rev}:{path}'], text=True)
 i = s.index(start); j = s.index(end,i) if end else s.index('\n\n',i)
 return s[i:j]
for path, name, start, end in ranges:
 row = {'path':path,'range':name}
 for stage, rev in (('pre',pre),('post',post)):
  hits = pat.findall(block(rev,path,start,end))
  keys = [h if h.lower().startswith('rea-agents@') else 'skill:'+re.search(r'v\d+',h,re.I).group().lower() for h in hits]
  row[stage] = dict(sorted(collections.Counter(keys).items()))
 print(json.dumps(row,sort_keys=True))
PY
```
