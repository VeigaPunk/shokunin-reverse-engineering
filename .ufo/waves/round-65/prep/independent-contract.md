# Independent prospective Kaidoku65 contract

Written before candidate reader implementation or scored data, 2026-11-03. Reviewer owns construction oracle; author owns reader. New claim is bounded ar name resolution and physical member inventory, not universal archive validity, safe execution, symbol-index validity, signature verification, or linker member selection. Every member is inert bytes, never extracted or executed.

Profile agreed with author: maximum archive 1048576 bytes, 128 physical records, 65536 stored body bytes per record (BSD name bytes included). Normal magic !<arch>\n; thin !<thin>\n unsupported before following any reference. Each header is 60 bytes, followed by stored body and newline pad if stored length odd. Size decimal digits plus trailing spaces only. Other header fields are opaque metadata; no validity claim on timestamps, UID, GID or modes. Final slash on simple name is removed; plain short names accepted. Printable ASCII resolved names only, no NUL. Names including ../ are retained strictly as metadata. GNU // is one preceding string table of nonempty printable names each terminated /\n; /decimal resolves only a table-entry start. GNU / is an opaque symbol table. /SYM64/ and other unrecognized slash forms unsupported, not interpreted. BSD #1/N requires positive decimal N<=stored body, takes first N bytes as printable name, hashes only remaining bytes. Mixed per-member naming accepted as this profile, not a dialect certification. Symbols or names inside an inline BSD member are ordinary members, not magically special.

Success exact JSON keys schema,exit,finding,archive_sha256,archive_size,occurrences. schema integer1; exit integer0; finding complete. Each physical occurrence exact keys ordinal,header_offset,kind,name,stored_size,payload_size,payload_sha256. kind member/name_table/symbol_table; metadata tables retain names // and / and hash raw stored bytes. All integer fields are actual integers, never bool; lowercase full SHA256. Error exact keys schema,exit,finding; no partial inventory. Wrapper adds binding outside reader output, not in it.

Refusals are first applicable at archive budget, magic, count at new record, complete header/trailer, size syntax, member budget, payload availability, pad, then naming. Input must be regular nonsymlink. Invalid input/error exits fixed by fixtures. Positive empty archive and boundary controls mandatory. Scope does not claim exhaustive validation beyond these cases.

Admission: every frozen expected field and exit must match independent construction oracle on fresh post-freeze bytes. Exact-case set bound by hash. Independent controls must fail: no output/exit0; boolean numeric; duplicate JSON key; stale dev hash replay; collapse equal names; hash BSD name+body; count symbol table as member; ignore GNU offset. Source-backed craft and limitations required. Reader, comparator and fixture recipe exercised with development instances before freeze; no data produced or labeled scored until exact freeze commit. After freeze no predicate/reader/oracle edits; preserve first failed answers and report rejection rather than repairing their pass.

Sources read directly in reviewer session: https://man.netbsd.org/ar.5 (BSD header widths, size includes name, even padding); https://sourceware.org/binutils/docs/binutils/ar.html (thin archives refer to external originals); https://raw.githubusercontent.com/llvm/llvm-project/main/llvm/lib/Object/Archive.cpp (getName, GNU string offsets and /newline termination, BSD inline length). These are source observations, not runtime parity. No source files copied and no direct prose quotes retained here.
