## 1. Verdict

**FAIR NATURAL CONTROL — CONFIRMED, with two scope caveats for the parent.**
The control run holds every parameter of round-7's mitigated hold constant
— same target bytes, same argv, same npx cache pin, same Ghidra/JDK/heap,

application channels of the treatment). No confound touches the
attribution channel: the kill is cgroup-local (kernel memcg OOM at the
unit's own caps), insulated from host ambient pressure. **The natural leg
died: `Result=oom-kill` at 2026-10-18 19:53:10 -03** — per the C3 design,
kill ⇒ the disable is proven necessary (attribution confirmed), supporting
the HELD→append-only correction of the r7 entry's attribution sentence.

Caveats: (a) scope the necessity claim to the sealed envelope
(9G/1G/7200s) — the control proves necessity *under this envelope*, not
that the artifact is unanalyzable at any memory bound; (b) REA's error
envelope mislabels the death `category: cancelled` / "Ghidra startup was
cancelled" — classify the kill from the journal, never the envelope
(round-4 precedent, `SCORECARD.md:1114-1115`).
