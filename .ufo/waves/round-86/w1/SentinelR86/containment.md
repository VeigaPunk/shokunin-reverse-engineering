## Verdict summary

- (a) No write outside `--json-out` and `--work`: HOLDS for the counters' own code (C-12). FAILS through the G3 row command (C-2, C-3) and through `--json-out` clobbering frozen `pre/` files (C-13).
- (b) No `/tmp` hardcoding: HOLDS (C-11). `/tmp` is the default only when TMPDIR is unset.
- (c) gate-registry executes only the row's declared argv, no shell, bounded env: no shell and a four-key env for the tool children HOLD (C-4, C-5). FAILS on "the row's declared argv" meaning the named tool: arbitrary argv, including `python3 -c`, runs and can go green (C-2). FAILS to isolate the git children's env (C-6).
- (d) A path from a registry cell cannot escape `--root`: pinned cell HOLDS (C-9, C-10). The command cell FAILS (C-3).
- (e) Neither counter mutates the lane tree: HOLDS for the production passes (C-14). The S255 rule is violated by gate-registry's G2/G3 (C-1).
