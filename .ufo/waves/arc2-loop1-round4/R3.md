   version (`REA 6.7.0`), the census returns `FAIL undeclared=1`, exit 1 — the
   round re-breaks its own measurable in the same commit that fixes it. Written

   cover the append (`635,900`) plus a receipt-bearing appended section also
   holds (`PASS`, §2.6). This is E20's constraint #2 and E16's "two landings"
   restated with the endpoints measured.
5. **VERDICT-WEAKENING VECTOR — an open-ended DATED bound launders any future
   stale append; a fixed bound does not.** I measured the E20-recommended form
   (`703, 9999`) against a card whose round-4 section asserts ``the live Kimi
   pin is rea-agents@6.4.0 at ~/.kimi-code/config.toml:1287`` — a false current
   statement: **`VERDICT: PASS`, exit 0.** The same card under the fixed bound
   `635,766` is **caught** (`FAIL undeclared=1`, exit 1) because the appended
   block falls outside every declared range. A fixed overshoot bound
   (`635,900`) launders that same card, because the overshoot range is DATED.
   **Recommendation: use the fixed bound that exactly covers the bytes the
   round lands (`635,766` if the records append is written version-token-free;
   `635,<end>` measured at the work commit otherwise), and never an
   open-ended or overshooting bound.** Note the boundary of this claim: an
   open-ended bound is *worse* than a fixed one, but a fixed DATED bound still
   launders in-range statements (§2.5) — no bound choice fixes that.

   round's own claim.** Apples-to-apples on the same pristine card with the

   receipt edit at all**. So the exemption converts the round's own two-part
   move (re-key **and** receipt language) into a one-part move and lets a
   receipt-less declaration claim PASS. That is the weakening.

   discriminate an honest re-key from a whitewash — a whole-file DATED

   constraint. G11's discriminating power on a real round-3 locus is recorded

7. **SECOND, INDEPENDENT WEAKENING SURFACE — a mixed-disposition block is
   reclassified `info` and disappears from both the verdict and the JSON.**
   When one block holds both a false current statement and a true one, the
   block-level disposition falls through to `else: disp = "info"`

   green census is weaker evidence than it reads. The instrument is not yet
