```markdown
## Wire-it amendment — roster-to-dispatch gate (arc2-loop1-round9, append-only)

The rules above require a frozen roster and an items-array count. This amendment makes both a dispatch-boundary contract, not a retrospective checklist.

- **Freeze the input.** Before the first dispatch attempt, save one roster artifact under `.ufo/waves/<round>/receipts/`, with one row per logical seat and fields for a unique logical-seat ID, scope, and expected report path. Record its exact path, SHA-256, and declared seat count in the pre-dispatch record. Do not rewrite the frozen bytes; correct a roster only by a separately named, hashed artifact with the reason recorded before the affected dispatch. Never derive this wave's roster from another round or from reports found after dispatch.
- **Bind and gate the dispatch.** Preserve the exact `items` array/payload submitted to the dispatcher as a receipt and bind the checker to that same payload. The parent dispatch path must run the checker immediately before submission and refuse to dispatch on any nonzero result. PASS requires: unique roster IDs and report paths; unique IDs in the payload; declared count = roster row count = payload items-array length; and exact equality between roster IDs and payload IDs (no missing or extra logical seats). Print the three counts and both set differences. An absent, unparseable, or unbindable payload is `could-not-evaluate`, never PASS. Same-size but different-seat lists must fail.
- **Reconcile delivery against the frozen slots.** After dispatch, record one reconciliation row per roster ID, including attempt/replacement IDs, expected report path, and whether a valid report was received. Count unique completed logical seats, not files or attempts; deduplicate replacements by logical ID. Report unique valid reports / actual dispatched items and enumerate unresolved, missing, or extra IDs. A shortfall is a dispatched-but-unresolved roster slot only when the frozen roster and captured payload prove that slot was sent; a roster/payload mismatch is a count-integrity failure, not a fictional non-completion. Apply the existing replacement rule only to confirmed unresolved logical slots.
- **Make the closeout replayable.** Record the frozen roster and payload paths + hashes, exact checker/enumeration commands and versions, outputs and exit status, declared/roster/items/completed counts, per-slot differences, replacement batches, and append-only correction pointers. Keep claim adjudication separate from delivery counts. A post-dispatch recount without the pre-dispatch artifact is an audit observation, not a passing dispatch gate.
```
