   recipe**; the equivalence anchor holds and is what attributes runtime bytes.
2. **"runtime bytes are not the flags-run's bytes"**: `--bin-runtime` is unsupported
   (measured), so attribution rests on the byte-identical creation anchor, not assumption.
   Verdict: **attributed with the anchor cited**.
3. **"compiles are nondeterministic"**: reran every leg (CLI on/off, JSON on/off, incl.
   metadata) in separate outdirs. Verdict: **deterministic, byte-identical**. One early
   false "DIFFERS" came from a path-prefix bug in my own compare loop (`carrierA.carrierA.*`);
   corrected comparison and a directory dump both show identical files — recorded so the
   false alarm cannot creep into the round.
4. **"every PUSH4 constant is a selector"**: refuted — `0x6508d58f` is the *encoded*
   `stamp()` literal `0xca11ab1e` (solc strips trailing zero bits; `0x6508d58f << 1 ==
   0xca11ab1e`, compiler legacy assembly `PUSH 6508D58F; PUSH E1; SHL`), and `0x43000825`
   lies in the CBOR metadata region (boundary computed: CarrierA code ends 1372). Verdict:
   **sweep artifacts identified**; dispatch compare sites push plain selectors.
5. **"the plan's numbers were copied, not re-derived"** (identity discipline): all plan
   targets reproduced from my own bytes (runtime `544469b7…`, creation `919fdef4…`, hex
   file byte-identical, anchor @13, Panic pc 659, K=5). Verdict: **pre-measurement confirmed**.
6. **"source revision invalidates the pins"**: both sources re-hashed at close; unchanged.
7. **"seat-line scope could be satisfied by one carrier only"**: the round carried three
   "carrier A" readings; compiling both solc candidates removes the ambiguity at ~2 s of
