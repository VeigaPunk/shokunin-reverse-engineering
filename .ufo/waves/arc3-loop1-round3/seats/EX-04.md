## 4. Attacks / refutations attempted, with verdicts

- **A1 raw-on-hex-file trap** (r1 recorded, re-run on carrier B): feeding the hex
  *text* file to `raw` decodes ASCII as code — exit 0, 0 functions,
  `bytecode.sha256` == the hex FILE's sha256 (`7dc26d4d…`/`54b8c906…`),
  `discovery_completeness:"unknown"`. **Verdict: reproduces on a new carrier;
  parsed-and-empty, not an error — a probe-input trap, not a carrier defect.**
- **A2 offset semantics, self-refutation:** a first-match-only regex scan suggested
  1/11 offset mismatch (`confirmationCount`, GT node target 98/99 vs probe 375/494).
  Re-scan over *all* compare legs per selector: probe offset = the EQ leg target for
  every selector, all JUMPDESTs. **Verdict: my first scan was wrong; the probe's
  offsets are correct 11/11 on both legs; mechanism recorded (binary-search split
  node).**
- **A3 pure/view conflation:** the compiled ABI says `pure` for
  `computeTxHash(address,uint256,bytes32,uint256)`; the probe's
  `inferred_state_mutability` says `view`, both legs. **Verdict: upstream inference
  separates mutating from non-mutating, not pure from view — first pure leg in this
  carrier family; recorded as this round's delta, not a defect** (r1 entry already
  frames mutability strings as upstream inferences).
- **A4 false-positive check on the optimizer leg:** opt200 carries an extra
  non-dispatch PUSH4 immediate `4e487b71` (Panic(uint256)) @pc 1777 absent from the
  noopt leg (13 vs 12 PUSH4 sites). The probe did not report it. **Verdict: zero
  false positives on the optimizer-enabled leg — r1's zero-FP observation extended.**
- **A5 ERC-20 shape check:** none of `06fdde03/095ea7b3/18160ddd/23b872dd/313ce567/70a08231/a9059cbb/dd62ed3e`
  appears in either leg's runtime. **Verdict: non-ERC-20 shape holds; the carrier is
  admissible for the claim's "non-ERC-20-shaped carrier" leg.**
- **A6 self-attack — planted-set retrofitting:** a skeptical reader could ask whether
  the planted table was written after seeing the probe output. Evidence: scratch
  mtimes 9.3 s before the first envelope; three-way compiler-authoritative derivation;
  and the set is re-derivable by any third party from the frozen source + pinned solc
  (`compile-b.js` + `plant-b.js`). **Verdict: retrofitting would be detectable and is
  not needed; residual weakness named in §5.**
