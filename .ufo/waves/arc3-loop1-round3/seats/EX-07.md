1. **Planted-K forgery / post-hoc fitting** — planted file predates the first carrier-A
   probe by 41 s (`stat`), and its 9 selectors re-derive from the ABI signatures with
   an independent keccak-256 (self-tested against known vectors). Verdict: PASS.
   (Self-caught own bug: the intermediate `Rv2TokenOpt.planted-K.json` first used full
   32-byte hashes, then NIST `sha3_256` instead of Keccak — the oracle check caught it;
   final file `cf0dc751…` records the correction. Identity re-derived, stale
   comparison output deleted.)
2. **Decoy / custom-error PUSH4 leak** — 5 non-selector PUSH4 constants in carrier A
   (incl. `NotOwner()` selector twice on revert paths); none reported. Verdict: zero
   false positives.
3. **Raw/hex wrong-form confusion** — hex-as-raw: exit 0 with an empty function list
   (hazard, re-confirmed on the second pin); bin-as-hex: typed refusal, exit 1
   (fail-closed). Verdict: hazard exists but is detectable only via
   `normalized_result.artifact` vs `bytecode` sizes/digests — the leg comparison here
   uses the decoded digest, never the subject digest alone.
4. **Offset-semantics regression (r4 erratum)** — all 9 probe offsets equal JUMPDEST
   destinations on an optimizer-enabled carrier. Verdict: holds.
5. **Strict chain parser portability** — r1's strict 11-byte parser returns an empty
   chain on the GT-split shape. Verdict: parser limitation recorded; the K/K result is
   from the probe, independently re-derived by an EQ-window scan.
6. **`ev_` id content-addressing hypothesis** — refuted by measurement: same bytes,
   same pin, different path → different id; cwd/delay irrelevant. Verdict: id domain
   includes version + path + bytes + parameters.
7. **Mutability inference == ABI** — refuted for `pure` (`stamp()` reported `view`).
   Verdict: inference boundary recorded; do not cite mutability as ABI truth.
8. **Partial-recovery costume** — not applicable: no leg showed K' < K; both sides
   (`missing`/`extra`) printed on every row.
