usage: record.py [-h] --root ROOT --rev REV [--no-battery] [--selftest]
                 [--json-out JSON_OUT]

Round-47 C2 counter — the lane's current self-assessment, re-derived atom by
atom. Reads the last two `## Round N` sections of `SCORECARD.md` at `--rev`
and compares every machine-checkable atom with committed repo state: seats
`Waves: A + B = C seats` / `Wave 1: A seats; wave 2: B seats` derived from
`.ufo/waves/round-N/*-dispatch.json` -> counts.spawn, in file order window a
sentence claiming a `git log …` "is empty" over `X..Y -- paths` derived by
running the same log at --rev; a `<tip>`/`<REV>` placeholder is `unverifiable`
and counts as a mismatch path every `.ufo/waves/…` token in the sections ->
exists at --rev rev every backticked 7–40 hex token -> resolves and is an
ancestor of --rev Repairs append a `## Record corrections — round 47` section.
Each `- corrects <class> <key>: <statement>` line exempts the atoms it names
and is itself re-derived; a correction that disagrees with committed state
keeps the atom red. Exit codes: 0 met; 1 not met; 2 could-not-evaluate.

options:
  -h, --help           show this help message and exit
  --root ROOT
  --rev REV
  --no-battery
  --selftest
  --json-out JSON_OUT
